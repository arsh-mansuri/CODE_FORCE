## ⚡ Technical Execution Guidelines

1. **Backend**: FastAPI app with automatic `/docs` swagger documentation. Keep models clean and self-documenting. Include `seed_db.py` to populate realistic candidate profiles.
2. **Frontend**: Vite + React with TypeScript and Vanilla CSS. Implement tactile card swipe physics (drag/touch + arrow keys), interactive Sperner rent sliders, and instant match celebrations.
3. **Defense Against Wi-Fi Failure**: Keep client-side algorithm fallback active so that if the venue network fluctuates, the judges still experience fluid swiping and instant rent recalculations.
4. **Git Discipline**: Meaningful commit cadence every 1–2 hours across all team members.
